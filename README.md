# 证监会每日审批爬虫

GitHub Pages 站点 + WorkBuddy 技能包。

## 本地预览

用浏览器打开 `index.html`，或：

```bash
cd csrc-scraper-site
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 发布到 GitHub Pages

1. 将本目录推到 GitHub 仓库（建议仓库名 `csrc-approval-scraper`）
2. Settings → Pages → Source 选 `Deploy from a branch` → Branch `main` / root
3. 同事访问：`https://<你的用户名>.github.io/csrc-approval-scraper/`

## 技能包

- 下载：`downloads/证监会每日审批爬虫.zip`
- 源码：`skill/`

WorkBuddy：技能页 → 上传 / 导入本地 Skill → 选 zip。
