能做什么

面向日常盯盘与业务汇报，把「查官网 + 抄表」变成一次导出。

进度台账

进度汇总、债券类全量、同批对比、重复注册等 Sheet 一次生成，国泰海通行自动高亮。

同业对标

勾选或点名对标机构，单独导出对标同业 Excel，方便看同一天、同类型谁快谁慢。

两种用法

WorkBuddy 对话选「今日 / 昨日」快速出表；也可本地打开图形界面细调参数。

给同事：三步装上

比微信发 zip 更稳——统一从这个页面下载最新包。

1

下载技能包

点击上方「下载 WorkBuddy 技能包」，得到 证监会每日审批爬虫.zip。

2

导入 WorkBuddy

打开 WorkBuddy → 技能 / 技能市场 →「上传技能」或「导入本地 Skill」→ 选中该 zip。

3

对话里用

说「跑一下证监会今日审批」或「昨日 + 常用对标」。首次需安装依赖（见下方）。

推荐 · WorkBuddy

对话流程

  1. 选时间段：今日 / 昨日 / 指定日 / 区间（长区间会慢）
  2. 选对标：不要对标 / 常用对标 / 点名若干家
  3. 等待导出路径，在技能目录的 输出/ 下取 Excel
