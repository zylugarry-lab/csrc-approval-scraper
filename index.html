CSRC APPROVAL TRACKER

证监会每日审批爬虫

网页版操作台：勾选日期与对标机构，一键导出 Excel。界面已重新设计，可公开分享给同事使用。

打开网页版操作台 GitHub 源码
当前公开地址依赖本机服务在线（临时隧道）。若打不开，请让部署人保持电脑运行，或按下方 Render 做成 7×24 常驻站点。 第一次打开 loca.lt 若出现提示页，点 Continue 即可。

页面能做什么

  • 今日 / 昨日 / 单日 / 日期范围
  • 搜索并勾选对标机构，或一键「常用对标」
  • 开始爬取后自动下载 Excel（有对标时为 zip）
