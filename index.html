CSRC · Web GUI

证监会每日审批爬虫
网页版操作台

同事在浏览器里勾选日期、对标机构，点「开始爬取」即可下载 Excel——交互和桌面 GUI 一样。 GitHub Pages 只能放说明页；真正可勾选操作的网页版需要跑下面的服务（服务器代为请求证监会接口）。

为什么不能整站静态托管？ 浏览器直接访问证监会接口会被跨域拦截。网页版必须有一台能上网的机器跑后端（本机 / 内网服务器均可）。

启动网页版 GUI（本机或服务器）

cd webapp
pip3 install -r requirements.txt
python3 app.py

# 浏览器打开
http://127.0.0.1:8787

同一局域网同事可访问：http://<你的电脑局域网IP>:8787

页面上能勾选什么

  • 日期：今日 / 昨日 / 单日 / 日期范围
  • 对标机构：搜索、常用对标一键勾选、多选
  • 可选：ETF 新主题全历史（默认不勾，更快）
  • 点「开始爬取」→ 自动下载 Excel（有对标时为 zip）
